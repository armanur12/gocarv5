# CarGoRuqsat Android v5

Полный Android-проект с WebView для car.qoldau.kz.

Функции:
- выбор целевой даты;
- время отдельно не задаётся: проверяется любой доступный час выбранной даты;
- интервалы 3/5/10/15/30/60 секунд;
- строгая повторная проверка даты перед кликом и перед «Сохранить»;
- не обходит CAPTCHA, ЭЦП, SMS или авторизацию.

В GitHub Actions workflow `Build APK` собирает debug APK.
Важно: DOM сайта может меняться, поэтому при изменении разметки потребуется обновить JS-селекторы в MainActivity.kt.
