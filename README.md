# CarGoRuqsat Catcher Android v5 — Strict Date

Версия соответствует расширению v5:
- выбираются только нужные даты;
- время НЕ выбирается: подходит любое время 00:00–23:59;
- интервал проверки: 3/5/10/15/30/60 секунд;
- перед кликом слот должен принадлежать выбранной дате;
- перед «Сохранить» дата проверяется повторно;
- после срабатывания ловля останавливается и приходит уведомление.

Сборка:
1. Открыть проект в Android Studio.
2. Дождаться Gradle Sync.
3. Build -> Build APK(s).
4. Установить APK на Android.

Важно: авторизация, ЭЦП, SMS и CAPTCHA не обходятся. Автоматизация работает внутри открытого WebView; изменения разметки сайта могут потребовать обновления JS-селектора.
